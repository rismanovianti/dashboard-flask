Kesimpulan

Standar deviasi menunjukkan seberapa besar penyebaran data terhadap nilai rata-ratanya.

Semakin kecil standar deviasi, semakin dekat data dengan nilai rata-ratanya. Semakin besar standar deviasi, semakin bervariasi data tersebut.
